# **AI Image Detector Dashboard**

A modern React UI for image verification using AI-powered status evaluation.
Built with **Material UI (MUI)**, responsive grid layout, dynamic status buttons, and clean card-based design.

---

## 🚀 Features

* 📸 Image cards with fixed dimensions
* 🎨 Dynamic status highlighting (green / yellow / red)
* 🔘 “AI Check” button that updates label + color on click
* 🖼️ Local image support
* 📱 Fully responsive grid
* 🎨 Light / dark mode logo switching
* ⚡ Modern React + MUI architecture

---

## 🛠️ Tech Stack

* **React**
* **Material UI (MUI)**
* **Vercel optimized setup**

---

## ▶️ Running the Project

### **Install dependencies**

```bash
npm install
```

### **Start development server**

```bash
npm start
```
